# SIE–NC Weekly 회의록

주간 정기 회의 기록을 하나의 HTML 페이지(`index.html`)로 관리합니다.
브라우저로 `index.html`을 열면 좌측에서 회차를 선택할 수 있습니다.

## 새 주차 추가 방법

`index.html` 하단 `<script>` 안의 `MEETINGS` 배열 **맨 앞**에 객체 하나를 추가하면 됩니다.
(최신 회차가 위로 오고, 기본으로 열립니다.)

```js
{
  id: "2026-09-23",          // 앵커/URL 해시로 사용
  label: "2026-09-23",
  sub: "9월 4주차",
  title: "SIE–NC Weekly — 2026년 9월 23일",
  meta: [["일시","..."], ["소요","..."], ["기록","..."]],
  summary: "한 문단 요약",
  headlines: ["핵심 1", "핵심 2"],
  carryover: [["지난 회차 항목","현재 상태","done"]],          // 선택
  topics: [{
    tag: "deal",             // deal | legal | ops
    tagLabel: "Deal",
    title: "주제",
    points: ["논의 내용"],
    stance: [["NC","입장"], ["SIE","입장"]],        // 선택
    risk: "리스크 문구"                              // 선택
  }],
  decisions: ["합의 사항"],
  actions: [["담당","할 일","기한","open"]],        // open | done | hold
  open: ["미결 이슈"],
  quotes: [["화자 00:00","원문 발언"]],
  caveats: ["기록 유의사항"]
}
```

## 원칙

- 자동 전사(Clova Note) 기반 정리이므로, 숫자·고유명사는 원문 확인 후 확정합니다.
- 법률 관련 언급은 참석자가 인용한 자문 내용을 그대로 기록하며, 법적 결론으로 쓰지 않습니다.
- 양측 표기는 `NC`(당사) / `SIE`(상대측)로 통일합니다.
- 화자 번호는 전사 파일별로 독립 부여되므로, 회차 간 동일 번호를 같은 인물로 보지 않습니다.
- 대외비 문서입니다.
